À propos .ntm contre .mid + Repiquage + Vitesse

.ntm - Note Tuning Music - Complet, recommandé. Fichier JSON. Sauvegarde notes + NOM de voix + Réf + Tempérament + Tonique + Gamme + Accord + Accord Seulement + changements en cours de morceau + courbe de hauteur continue + courbe de volume.

.mid - Ancien, limité. Sauvegarde notes + vélocité + un seul changement de programme. Il perd accordage, tempérament, Réf, noms de voix, et courbes. Sine et piano deviennent tous les deux programme 0.

Notation par défaut dans cette version française : Do Ré Mi. Tu peux changer pour C D E dans JOUER si tu veux. Le choix est enregistré dans le .ntm.

Voix : Les boutons montrent Sinus, Guitare, Basse, Flûte, Orgue, Cordes, Nappe. En dedans, le .ntm garde sine, guitar, bass, flute, organ, strings, pad, pour rester compatible avec la version anglaise.

Vitesse / Octave - Vitesse de bande : 0.5x = demi tempo, fréq / 2, octave grave. 1x = normal. 2x = double tempo, fréq * 2, octave aiguë. C'est comme ralentir une bande ou l'accélérer. Cela ne change pas le .ntm sauvegardé, seulement comment il joue.

Repiquage : Dans JOUER, coche Repiquage, puis appuie sur Démarrer Enr. pendant que le LECTEUR joue. Le LECTEUR continue en fond, le volume baisse pour éviter la saturation, les nouvelles notes s'alignent sur la même ligne du temps. Si Repiquage est décoché, le LECTEUR s'arrête quand tu appuies sur Enr.

Formule de fréq : fréq = réf * 2^((midi-69)/12) * 2^(cents/1200), cents depuis TEMP_MAP[temp][semi]. Pour Gliss OFF/OFF, fréq continue depuis baseMidi = 24+tonique+curved*84.
